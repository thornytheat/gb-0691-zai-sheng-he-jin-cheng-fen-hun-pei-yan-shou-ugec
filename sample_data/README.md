复配补料（M7整组补料）专用样例：

- reblend_demo.csv：五个炉次的多炉次演示输入。F-3101为急单且Cu偏低，F-3102 Zn偏低，F-3103 Cu偏低且耗料大，F-3104已合格免补料，F-3105 Cu超上限、现有补料无法修复。复配页可点“载入多炉次演示数据”直接运行。
- reblend_inventory.csv：共用补料库存种子（电解铜、锌锭、黄铜回炉料，含各元素干基化验与现有量），首次访问补料接口时自动建表导入。
- reblend_orders.csv：炉次交期与急单优先级种子，决定整组分配顺序。
